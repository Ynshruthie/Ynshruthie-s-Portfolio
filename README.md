# 🌟 Ynshruthie's Digital Portfolio

Welcome to my personal digital universe! This portfolio is an interactive, magical, and dual-themed web experience showcasing my journey as an **Aspiring Software Professional** and **Content Creator**.

## 🔮 Two Worlds, One Portfolio
This site features a unique branching layout that allows visitors to explore different facets of my work:

- **💻 The Tech Realm** (`tech.html`): A deep dive into my software engineering journey. Here you'll find my technical projects (like Trip On Network and Esports Oracle), my programming skills (Python, Java, C++, JS, etc.), my internship experience, and academic milestones.
- **🎨 The Content Creator Realm** (`content.html` & `dashboard.html`): A vibrant space dedicated to my creative endeavors, UGC (User-Generated Content) packages, audience demographics, and social media presence.

## 🚀 Features
- **Interactive Intro & Scene Selection**: A cinematic entry experience leading to a beautiful interactive gateway.
- **Dynamic Content Modals**: Resumes, mark cards, and certificates can be viewed in elegantly designed glassmorphism modals.
- **Real-time Social Statistics**: Integrated GitHub Actions (`fetch-stats.js`) to auto-update my social media metrics dynamically.
- **Responsive & Modern Design**: Built with vanilla HTML, CSS, and JS using modern styling, cinematic animations, and a rich aesthetic palette.

## 🛠️ Technology Stack
- **Core**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with CSS Variables for vibrant themes, smooth transitions, and keyframe animations.
- **Icons & Fonts**: FontAwesome, Google Fonts (Outfit, Playfair Display, Great Vibes, Syne, Caveat, Nunito).
- **Automation**: GitHub Actions & Node.js for updating dynamic content.

## 📂 Project Structure
- `index.html` & `style.css`: The magical entry gateway and world selection.
- `tech.html` & `tech.css`: The software engineering portfolio realm.
- `content.html`: The content creation and influencer realm.
- `dashboard.html` & `dashboard.css`: The advanced metrics and UGC analytics dashboard.
- `profile.html` & `profile.css`: The digital ID and personal bio section.
- `assets/`: Contains all images, certificates, resumes, and media files.
